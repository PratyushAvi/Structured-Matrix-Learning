# Structured Matrix Learning

This repository hosts living documents that expand upon the work in: **[Query Efficient Structured Matrix Learning, COLT 2026](https://arxiv.org/abs/2507.19290)**.

Since obtaining the results in the preliminary paper, the mathematical capabilities of public large language models have been significantly expanded. For instance, standard publicly accessible LLMs (e.g. from OpenAI, Anthropic, and Google) are all able to improve our main $(3+\epsilon)$ approximation result for finite families to $(1+\epsilon)$ by bootstrapping off of the constant factor result. See the PDF [here](1+eps-finite-family-approximation.pdf). 

We make these proofs and reports available in this repository. While the results themselves have been human verified, they have not been rewritten or re-formatted by us. We may polish or add exposition to these in the future and invite anyone else interested to contribute as well.
